# 流程

## 地城探索

### 基础

- 地城探索循环（见下）由一系列**轮**、**行动**及其后果构成。
- 在角色的**轮**内，其可移动至多等同于火把光照范围的距离（约 40 英尺），并执行一次**行动**。玩家也可将**行动**用于移动，距离至多为此三倍，但会增加触发[**地城事件**](#dungeon-events)表格掷骰的概率。
- **监守**应自由、无代价地提供关于某区域及其危险的明显信息。快速移动或疏于防备，可能提高遭遇游荡怪物、触发陷阱或引发[**地下城事件**](#dungeon-events)表掷骰的几率。

> 尽管此处使用“地下城”一词，但它可指任何危险的场所（宅邸、农舍、冒险地点等）。

### 地下城探索循环

1. **监守**描述队伍周遭的环境与眼前的危险（战斗、陷阱、突袭等）。随后，玩家宣告各自角色的移动意图与**行动**。
2. 监守同时结算每个角色的**行动**，以及所有已在进行的**行动**。记住，每当监守拿不定主意时，命运骰都是趁手的工具！
3. 玩家记录一切资源损失与新增状态（如物品使用、*匮乏*等）。随后循环重新开始。若有必要，**监守**应在[**地城事件**](#dungeon-events)表上投骰。解读结果时，切记结合常理判断！ 

### 地城事件 {: #dungeon-events }

探索地城总是危机四伏，时间必须时刻与风险相权衡——惊动此地的居民、遭遇自然险情，乃至更糟的东西。 
当队伍：

- 在单个房间或地点停留超过一个地城循环 
- 匆忙或胡乱地穿过房间
- 进入新的区域、楼层或地带
- 制造巨大动静

**在下表中掷骰。**

|       |                 |                                                                                                           |
| :---: | :-------------: | :-------------------------------------------------------------------------------------------------------: |
| **1** | **遭遇** | 在遭遇表上投掷。可能是**敌对**的。（见[反应](/players-guide/core-rules#reactions)。） |
| **2** | **迹象** | 发现线索、兽迹、踪迹、废弃巢穴、气味、受害者等。 |
| **3** | **环境** | 周遭生变，局势升级。水位上涨，洞顶坍塌，仪式将成，诸如此类。 |
| **4** | **损失** | 火把熄灭、持续中的法术失效，诸如此类。队伍须先处理完该效果，方可继续前进。 |
| **5** | **力竭** | 队伍必须休整（在此表上再投一次）、累积一点**疲乏**，或消耗 1 份口粮。 |
| **6** | **安静** | 队伍暂时独处（且安全）。 |

### 行动

- **动作**指任何非被动行为，例如*搜寻陷阱*、*强行开门*、*聆听危险*、*解除陷阱*、*与敌交战*、*施放法术*、*闪避陷阱*、*逃跑*、*休息*等。
- 有些**行动**有特殊规则（见下文），另一些则可能需耗费多个**回合**才能完成。
- 响亮或引人注目的**行动**也可能触发与地城居民的**遭遇**。

#### 搜索

- 角色可以花费一个**回合**，彻底搜索区域内**一个**物件或地点，找出相关的隐藏宝藏、陷阱、密门等。
- 较大的房间，以及艰险或复杂的地城地形，可能需要数个**回合**才能彻底搜索。
- 探索地城时，*先*搜索房间更为安全，但代价高昂：时间。

#### 休整

- 角色可花费一个回合**休整**，恢复全部**耐久度**。
- **休整**需有光源与*安全地点*。若危险当前或迫近，则无法**休整**。
- **休息**不恢复**疲乏**，因为在地下城中无法安全**扎营**。

### 恐慌

- 角色若被敌人包围、陷入黑暗，或直面最深的恐惧，便可能陷入*恐慌*。通常须进行一次**意志** **豁免**，以免失控而陷入*恐慌*。
- *恐慌*的角色必须在自己的**回合**用一次**行动**进行**意志** **豁免**，方能摆脱该状态。
- *恐慌*的角色**耐久度**为 0，战斗首轮无法行动，且其所有攻击均为*受损*。

### 地城元素

#### 光照
- 火把及其他放射状光源可照亮地城 40 尺，再远便只剩物体的模糊轮廓。火把持续燃烧，直至被角色或环境熄灭。
- 一支火把可点燃 3 次，之后彻底损坏。一盏提灯每罐灯油可重燃 6 次，但占用更多物品栏。
- 没有光源的角色可能陷入*恐慌*，直至处境得到改善。

#### 门

- 门与入口可能上锁、卡死或彻底堵死。角色可借助手头资源（铁钉、胶）或纯粹蛮力强行撞开门（或将门楔死）。
- 队伍的行进顺序决定了门后无论有什么，谁将首当其冲。
- 角色可以通过仔细观察（倾听、嗅闻等），察觉附近门后与墙后的生命迹象及其他凶险。

#### 陷阱 

- 面对谨慎的角色，监守应向其提供一切相关信息，使其有机会*避免*触发陷阱。粗心的角色会依剧情触发陷阱，否则有 2/6 的几率。
- **陷阱**通常可通过仔细**搜寻**房间来发现。
- 陷阱造成的伤害从属性（通常为**力量**或**敏捷**）中扣除，*而非***耐久度**。护甲可减免伤害，但仅限适用情形（例如盾牌无法减免毒气伤害）。

## 荒野探索

### 轮班

- 一天分为三个**轮班**，分别称为*清晨*、*午后*与*夜晚*。
- 每个角色每**轮班**可选择 *一项* [**荒野行动**](#wilderness-actions)。
- 若角色分头行动，每组均视为独立个体。

### 据点

- 地图上可能的目的地称为**据点**。
- 在地图上的两个**据点**之间跋涉，可能需要一个或数个**轮班**，具体取决于路线、地形、天气与队伍状态。
- 队伍对抵达目的地途中会遭遇何种挑战只有大致概念，却极少知晓具体细节。

### 旅行耗时

在《石冢》中，旅行时间以「轮班」计，每日分三个轮班，每班八小时。不过，多数队伍会选择将当日第三班用于休整，因此不妨以「天」作为旅行时间的简写。

若要确定两地之间的距离，须将路径、地形与天气难度表中的所有减值相加，并计入沿途这些要素的任何变化。经由水路旅行时，参照周边地形难度。若地形格外广袤，可为旅程增加至多 +2 轮班的减值。

天气、地形、黑暗、受伤的队员与其他阻碍都会影响旅行，甚至令其无法成行！有时，队伍须额外承受**疲乏**或消耗资源，方能维持行进速度。坐骑、向导与地图可提升队伍的旅行速度，甚至抵消某些减值。

每天，监守应依当前季节在天气表上投骰。若连续两次掷出“**极端**”天气，天气便转为“**灾难**”。狂风化作飓风，暴雨淹没山谷，诸如此类。

### 荒野探索循环

1. **监守**描述地图上当前的**地点**或**区域**，以及道路、天气、地形或队伍状态可能如何影响**行进速度**。队伍规划或调整前往目的地的路线。
2. 每名队员选择一项**荒野行动**。**监守**叙述结果，然后在[**荒野事件**](#wilderness-events)表上掷骰。队伍应对结果。
3. **玩家**与**监守**记录一切资源损耗与新增状态（如火把消耗、*匮乏*等），随后循环往复。

### 荒野事件 {: #wilderness-events }

|       |                 |                                                                                                                                                                                                                            |
| ----- | --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1** | **遭遇** | 就该地形或地点投掷遭遇表。若适用，别忘了为 NPC [反应](/players-guide/core-rules#reactions) 投骰。 |
| **2** | **迹象** | 队伍发现线索、踪迹，或附近遭遇、地点、隐藏要素的迹象，抑或有关附近区域的信息。 |
| **3** | **环境** | 天气或地形发生变化。 |
| **4** | **损失** | 队伍面临一个抉择：需付出资源（口粮、工具等）、时间或精力。 |
| **5** | **力竭** | 队伍遭遇阻碍，需竭力应对、小心处置，或被拖慢进度。这或许意味着耗费额外时间（并追加一次**荒野行动**），或将**疲乏**加入角色的物品栏，以示其困顿。 |
| **6** | **发现** | 队伍找到食物、财宝或其他有用资源。**监守**也可改为揭示该区域的主要特征。 |

### 荒野要素

#### 夜晚

- 队伍可以选择夜间赶路、白天休息，但夜行要慢得多，也凶险得多！
- 夜间出行总是更加危险！**监守**应在[**荒野事件**](#wilderness-events)表上投掷*两次*。
- 某些地形与天气在夜间反而更易通行（例如沙漠）。**监守**应将此类挑战与其他因素一并权衡。

#### 睡眠术

- 一天中的最后一个**轮班**，通常用于[**扎营**](#make-camp)行动。
- 角色通常每天都需要睡眠。任何超出轻微干扰的情况都可能抵消或取消睡眠的益处。
- 若队伍跳过**扎营**行动，则每人将一张**疲乏**加入物品栏，并陷入*匮乏*。此外，在睡眠匮乏状态下出行会使地形**难度**提升一级（即*简单*变为*艰难*）。

#### 光照

- 火把及其他辐射状光源可照亮队伍前方 40 尺，再远便只能勾勒出物体的模糊轮廓。
- 没有光源的角色可能陷入*恐慌*，直至处境得到改善。
- 环境状况（突起的阵风、尘土、水等）很容易吹灭火把。

##### 光源

- 一支火把可点燃 3 次，之后便会损耗。
- 提灯可无限次重新点燃，但需另备一罐灯油（6 次使用）。

### 野外行动 {: #wilderness-actions }

#### 旅行

- 旅行开始。附近区域的显眼地点、特征与地形会依其距离远近依次显现。此行动通常由全队共同进行，视作一次。
- 队伍投掷 1d6，以判定途中是否迷路。该风险可增可减，取决于路径的**难度**、地图、队伍技能与向导。
- 若迷失方向，队伍可能需花费一次**荒野行动**来重新找到路。否则，队伍将抵达其路线上的下一个**节点**。 

> 记住把迷路的结果与相应路径的**难度**作比对。 

#### 探索

- 一名或多名队员搜索大片区域，寻找隐藏之物、向前侦察，或小心行进。
- 发现一处地点（庇护所、村庄、洞穴等）或景物（间歇泉、地下河、搁浅的船等）。
- 即使当前区域已完全探索，仍需采取**旅行**行动才能*离开*。

#### 补给

- 一名或多名队员可狩猎、捕鱼或采集食物，获得 1d4 份**口粮**（每份可用 3 次）。每多一名参与者，获得更多收获的几率便随之提升（如 1d4 变为 1d6，最高可达 1d12）。
- 相关经验或装备也可能增加收获。
- 队伍可能遇到民居或小村庄，花费金币和一整个**轮班**即可补给。

#### 扎营 {: #make-camp }

- 队伍在荒野中停下扎营。每名队员（及其坐骑）消耗一份**口粮**。
- 设定**轮值守夜**，以便队伍能安然入睡。人数较少的队伍或许不得不冒险无人看守地睡眠，或分多日轮流睡觉。
- 得以休整的队员从物品栏中移除所有**疲乏**。

## 休整期

游戏间隙，玩家可从事多种活动，如研究、追查线索、提升技能或经营关系。一名玩家角色同时只能进行一项**休整行动**。此类行动不可在危险环境中进行，角色处于恢复期时亦不可进行。若某项行动会危及自身安全，角色便无法执行。

### 里程碑

对于需要分步完成的活动，**监守**会分配 1-5 个**里程碑**供玩家记录进度。每个**里程碑**代表一项综合性的非交互任务。**监守**可提出不同的策略以达成这些目标，各策略对应不同的**里程碑**。**监守**亦有权根据游戏中事态的发展，增设新**里程碑**或舍弃现有**里程碑**。

### 代价

玩家角色可进行一次**休整行动**并支付相应的**代价**，以完成单个**里程碑**。若角色无力支付**代价**，则须另寻他法达成目标。**代价**的几个示例：
- **金币**：直接从角色物品栏中支付金币。
- **资源**：非货币形式的代价，如物资、特定常见物品等。
- **声望**：以角色的名望、个性、风度、人脉等作为赌注。
- **损失**：献出某种具体而独特之物。一根手指、一个灵魂、一件**奇物**，等等。

有些**代价**可凭角色的技能、人脉或意志力减轻，甚至一笔勾销。例如，某位玩家角色早已攒下足够的名望，得以踏入某家声名显赫的机构，这笔**代价**便随之减轻。换作另一位角色，或许就没这么走运，只能靠自身的人格魅力硬撑。此时，监守应言明风险（如永久禁止入内、损失名望等）。随后该玩家角色进行一次**意志**豁免；成功则代价减轻，或完全免除。

## 休整行动

以下活动是玩家最常选择的**休整行动**。**监守**也可根据游玩需要自行设定行动。

### 研究

角色调查某个问题：一段失落或湮没的秘闻、一件失物的所在、某位要人的下落，诸如此类。采取此行动，玩家必须先有明确要解答的问题，并在游戏世界中找到角色可接触的**来源**。若角色没有**来源**，可花费一次**休整行动**去寻找，但能否找到并无保证。问题提出、合适的**来源**确定后，**监守**应给出相应的**里程碑**与**代价**。

#### 问题

一如既往，问题必须源自某次游玩中的亲历。

**示例：**

- “**东尼普尔的失落神殿**在哪里？”
- “**财富城**里谁懂得破解古代墓库？”
- “**卷曲病**的解药该往何处寻？”

#### 情报来源

**情报来源**是掌握角色所求答案之部分或全部的人物、地点、势力或实体。他们可能是 NPC、势力、灵体，甚至其他玩家角色。

##### 示例：

- **巧嘴凯尔**，**商人议会**的常客。尽管与该派系关系极佳，但若请其协助非法勾当，代价可能极为高昂。
- 一位**林中野人**，栖身于**刀锋森林**深处。队伍在此前的远征中与他相遇，那次会面不欢而散。但据说他识得百草的性味，通晓其疗愈之效。
- **木偶神殿**，一支游牧马戏团，足迹遍及已知与未知之地。**火雨**降下之时，就连林中生灵也准备弃家而逃，队伍曾在那时搭救过他们中的一名成员。若有人听说过那些被遗忘的所在，那便是他们。

### 训练

角色可以借助某件物品或某种能力提升技能，并在叙事或机制上得到明确结果。他们可能想用某件武器造成更高伤害，想降低在恶劣天气中迷路的几率，或想读懂古人的语言。玩家角色可以花费多次**休整行动**，以某件武器对练，逐周精进技艺；也可以远赴某位贤者的居所，通过短暂而密集的研习提升自我。

玩家必须具体说明想提升什么，以及可能与之同练的**导师**。当然，角色精进的动机应源自游戏中的某段经历。**监守**应给出相应的**里程碑**与**代价**。

**示例：**

- **双手格挡**：空出一只手战斗时，角色的耐久度暂时增加1d4。队伍从**陨坑地**雇佣了一名雇员，那里的战士注重闪避敌人的攻击。她同意训练任何能在徒手格斗中击败她的人。
- **草药学**：只要有合适的材料，角色就能在**休整行动**中制作**治疗药膏**（恢复1d4点力量，1 次使用）。在**翠绿林地**接受一位年迈草药师的照料后，受伤的角色请求学习治疗之术。**大师**同意了，但要求他们在训练开始前采集三株稀有草药。
- **鳟鱼大师**：采取补给**行动**时，在寒冷淡水水源附近收集的**口粮**增加一档（例如1d4变为1d6）。队伍护送一位被困在臭名昭著的**银荒原**的自然学家安全返回城市。作为感谢，她提出训练一名角色识别并捕捉常见于较冷水域的湖鱼。

### 巩固关系

角色与游戏世界中的某个非玩家角色或派系建立联系。首先，他们须指明想要加深关系的对象，以及一个具体的**意图**（例如建立信任、修复友谊、谋求加入某派系、结成同盟等等）。随后，**监守**给出具体的举措（以**里程碑**与**代价**描述），供角色施行以推进这段关系。每当一个**里程碑**达成，**监守**便描述角色的关系如何发展或变化。

**示例：**

- 一次深入**根系**的探索无功而返，某玩家角色却发现队伍里不知何时混进了一名偷渡客：一只刚破壳不久的无眼吞噬者。众人决定留下这头生物，暗中驯养。
- 一次游戏进程中，某玩家角色与**头盔骑士团**的一名代理人交好。他深为教团的信条所折服，便打听加入需要什么条件。
- 某强大派系的一名代理人，在**群蛙之战**期间受队伍照看时殒命。如今责任方愿意作出补偿，好让队伍再度为该派系效力。
