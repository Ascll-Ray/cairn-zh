# 核心规则

## 属性

三项**属性**各适用于不同场合。（详见下文**豁免**。）

- **力量（STR）**：用于需要肉体力量的豁免，如抬门、弯折铁条、抵抗毒素等。
- **敏捷（DEX）**：用于需要平衡、速度、反应、闪避、攀爬、潜行、保持平衡等的豁免。
- **意志（WIL）**：用于说服、欺骗、审问、恐吓、魅惑术、激怒、操纵法术等的豁免。

## 豁免

- 豁免是一次投骰，用于规避冒险抉择带来的恶果。角色投 d20，将结果与相应属性比较。若结果小于等于该属性，则成功；否则失败。投出 1 必定成功，投出 20 必定失败。
- 若两名对手互相角力，处境最危险的一方进行豁免。
- 若两名角色需共同行动，处境最危险的一方进行豁免（通常是相关属性较低者）。

## 治疗与恢复

- 稍作歇息、饮些清水即可恢复失去的耐久度，但队伍也可能因此暴露。绷带可以稳定住遭受致命伤害的角色。
- 属性损失（见**致命伤害**）通常可借一周休养恢复，若有医者或其他得当的专人相助则更为顺利。
- 有些治疗服务分文不取，而魔法或更快捷的恢复手段则可能索取代价。

## 匮乏与疲乏

- 若一名角色缺乏关键需求（如食物或休息），即陷入**匮乏**。**匮乏**超过一天者，每过一天就往物品栏中增添一份**疲乏**。陷入**匮乏**的角色无法恢复耐久度与属性，也无法消除**疲乏**所占的栏位。
- 角色也可能因施法或剧情中的事件而被迫增添**疲乏**。每份**疲乏**占据一个栏位，直到角色得以休整（例如在安全之处睡足一夜）方可消除。
- 若角色被迫往物品栏中增添**疲乏**，却已无空余栏位，就必须从物品栏中丢弃一件物品。

## 护甲

- 计算耐久度所受伤害前，先从伤害掷骰的结果中减去目标的**护甲**值。
- 盾牌及类似护甲提供额外防御（如+1 护甲），但仅限持用或穿戴时生效。部分物品还可能依设定提供额外好处。
- 玩家角色、NPC 或怪物的护甲上限为 3。

## 反应

当玩家角色遭遇的 NPC 对队伍态度不明时，监守可投2d6并查阅下表：

|         |      |         |      |         |
| :-----: | :--: | :-----: | :--: | :-----: |
|    2    | 3-5 | 6-8 | 9-11 |   12    |
| 敌对 | 戒备 | 好奇 | 和善 | 热心 |

## 士气

- 敌人在首次出现伤亡时须通过意志豁免，否则逃跑；损失半数人数时再次豁免。
- 有些群体可用其首领的意志替代自身意志。落单的敌人耐久度降至 0 时须进行豁免。
- 士气不影响玩家角色。

## 雇员

- 冒险队伍可招募雇员，凭借其独特的技能、学识与训练协助探险。  
- 要创建一名雇员，请从市集中的[雇员](../marketplace#hirelings-per-day)表内选定合适的岗位。为每项属性投3d6，为其耐久度投1d6。给予其与身份相称的**装备**，再投角色特质表，进一步充实其形象。
- 或者，从[角色创建](../character-creation)指南中选定合适的[**背景**](../character-creation#backgrounds)与**姓名**。为该背景对应的表格投点（或从中挑选）。接着投口粮、金币、属性、耐久度与年龄。 

## 命运骰  

- 可选：当事件结果不确定时，或为模拟随机与偶然因素，投 1d6。
- 掷出 4 或以上通常对玩家角色有利，掷出 3 或以下则往往意味着玩家角色走霉运。

## 战斗

### 轮

- 一个**轮**约为游戏内十秒，双方轮流行动。每轮由能够行动的玩家角色先行，随后是他们的对手。*双方行动的结果同时发生*。 
- 在*战斗第一轮*中，每个玩家角色必须进行一次敏捷豁免才能行动。特殊情形、能力、物品或技能可以免除这一要求。豁免失败的玩家角色在本轮*失去其回合*。
- 随后其对手行动，第一轮结束。下一轮由玩家角色先行，随后是对手，如此往复，直至一方被击败或逃走，战斗结束。

### 行动

在其回合中，角色可以至多移动 40 英尺并采取至多一个行动。这可以是施放法术、攻击、再次移动，或其它合理的行动。每轮，玩家角色在掷骰前声明自己要做什么。若角色尝试有风险的行为，监守会要求相应的玩家或非玩家角色进行豁免。 

### 攻击与伤害

- 攻击方投掷武器伤害骰，减去目标护甲值，余数即对敌方耐久度造成的伤害。战斗中攻击自动命中。
- 多名攻击者攻击同一目标时，投掷所有伤害骰，只取最高结果。所有行动须先宣告后结算。
- 若一次攻击使某角色的耐久度恰好降至 0，请查阅[伤痕](#scars-table)表，了解其受到的独特影响。

### 攻击修正

- 若在劣势下战斗（如借助掩体，或双手被缚），攻击即为 *受损*，无论该攻击的伤害骰为何，攻击者一律投 1d4 点伤害。徒手攻击始终造成 d4 点伤害。
- 若在优势下战斗（如面对无力反抗的敌人，或使出大胆的招数），攻击即为 *强化*，攻击者可投 1d12 点伤害，取代其常规伤害骰。
- 具有 *群攻* 特性的攻击影响指定区域内的所有目标，需为每个受影响角色分别投骰。它可以是爆炸、巨龙的吐息，也可以是陨石的撞击。若不确定能影响多少目标，*投相关伤害骰，以结果为准*。
- 若同时以两件武器攻击，投两颗伤害骰，取其中最高者（以加号表示，如 d8+d8）。

### 致命伤害

- 使目标耐久度降至零以下的伤害，按剩余伤害量*从目标的力量*中扣除。目标须立即以*新的力量值*进行力量豁免，以免遭受**致命伤害**。豁免成功，目标仍能继续战斗（尽管力量值已降低），此后每次受伤仍须进行致命伤害豁免。
- 任何遭受致命伤害的玩家角色，都只能虚弱地爬行、挣扎求生。若获得救助（如绷带），伤势便会稳定；若得不到救治，将在一小时内死亡。NPC 与怪物若致命伤害豁免失败，由**监守**裁定视为死亡。此外，部分敌人拥有特殊能力或效果，会在其目标致命伤害豁免失败时触发。

### 属性损失

- 若玩家角色在战斗之外受伤，则改为扣除一项属性值，通常为力量。
- 玩家角色的力量降至 0，便会死亡；敏捷降至 0，便会瘫痪；意志降至 0，便会神志恍惚。敏捷与意志完全丧失的角色无法行动，直至通过长期休整或非凡手段恢复。

### 角色死亡

- 角色死亡时，玩家应创建新角色，或接管一名雇员。新角色立即加入队伍，以减少空耗时间。

### 分队

- 大群同类战斗单位协同作战时，视为单个*分队*。*分队*受到**致命伤害**时，即被击溃或遭重创。力量降至 0 时，便告覆灭。
- 单人对分队发起的攻击*受损*（*群攻*伤害除外）。分队对单人发起的攻击*强化*，并造成*群攻*伤害。

### 撤退

- 逃离险境时，必须通过敏捷豁免，且要有安全的去处。

### 远程攻击

- 远程武器可攻击任何近到能看清眼神的敌人。攻击特别远的目标时，攻击处于*受损*状态。
- 除非另有说明，否则无需记录弹药。

## 魔法

### 法术书

- **法术书**记载一道法术，占用一个栏位。无法轻易抄录或创造；只能从墓穴、地城与宅邸等地寻回。
- 法术书有时会显现出奇异的特性或限制，比如翻开时散发恶臭或非人间的气味，拥有与生俱来的灵智，或唯有在月光下方能辨读。
- 法术书会引来觊觎其中奥术之力者的注意，公然示人被视为危险之举。

### 施法

- 任何人都能施法：双手捧持法术书，出声诵读其中内容即可。此后必须在物品栏中加入一项**疲乏**。
- 若时间充裕且环境安全，玩家角色可以*强化*法术的效果（例如影响多个目标、增强其威力等），无需额外付出任何代价。
- 若玩家角色处于*匮乏*状态或身处险境（如在战斗中），监守可要求其进行意志豁免，以避免施法产生的任何负面影响。失败的后果与法术的预期效果相当，可能造成额外**疲乏**、法术书被毁、受伤，乃至死亡。

### 卷轴

**卷轴**与法术书相似，但：

- 它们*微不足道*。
- 不会造成**疲乏**。
- 使用一次后便会消失。

### 奇物

**奇物**是蕴含法术或力量的物品。它们不会导致疲乏。奇物通常使用次数有限，并具有**充能**条件。
