## 1. 零个人信息收集承诺
本参考文档网站为纯静态、开放获取的开源规则参考工具。我们**不使用任何 Cookie**，不主动收集、存储或分析任何访客的个人身份信息（PII）。

## 2. 静态边缘托管与访问日志
本项目托管于 GitHub Pages 与边缘 CDN 网络。在访问过程中，基础设施提供方可能会根据网络传输标准协议记录基础的网络请求日志（如匿名 IP 地址、User-Agent 与请求路径），该类日志仅用于抵御网络攻击与保障服务可用性，本站维护者无权亦不会将其用于用户画像追踪。

## 3. 本地离线偏好（Local Storage）
为提升跑团桌使用体验，本站的辅助功能（如暗色/亮色主题切换、离线掷骰历史记录）仅在您的**本地浏览器客户端（LocalStorage）**中存储。此类数据完全留存在您的本地设备上，绝不会上传至任何远程服务器。

## 4. 外部链接免责
文档内包含指向原作者官方商店（store.cairnrpg.com）及 itch.io 数字版页面的外部链接。当您离开本站访问第三方服务时，其隐私权与数据处理受该第三方平台的隐私政策约束。

## 5. 开源审计与监督
本站的前端编译与发布流水线完全开源。任何用户均可在 GitHub 仓库中自由审查全部源码、静态构建脚本与网络请求行为，确保零未经授权的数据外泄风险。
