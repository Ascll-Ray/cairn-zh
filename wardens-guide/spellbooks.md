# 法术书

|         |                       |                                                                                                                                                                                                                                                                                              |
| ------- | --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1** | **黏附术** | 一件物品被极黏的黏液覆盖。*相邻物品会以巨力粘在书上。* |
| **2** | **定锚术** | 一根坚固的金属线从你手臂中生出，固定在两侧五十尺内的两个点上。*若将绳索穿过书脊上的铁环，它便会重如大象。* |
| **3** | **活化物体** | 一件物品会尽力遵从你的命令。*如黏土般可塑。孩童的笑声从书页间迸发。* |
| **4** | **赋形化人** | 一只动物获得人类智力或人类外貌，持续一天。*依所受待遇发出呜咽、呼噜或低吼。* |
| **5** | **奥术之眼** | 你能透过一颗魔法浮游眼球视物，它随你号令四处飞行。*需喷些水才能睁开。* |
| **6** | **星界牢笼** | 一件物体被冻结在时空之中，封于坚不可摧的水晶外壳内。*寂静、抽象，其中面孔痛苦尖叫。* |
| **7** | **牵引术** | 两件物体若相距 10 尺以内，便会强烈地相互磁吸。*附近的罗盘徒劳旋转。* |
| **8** | **幻音术** | 你创造出虚幻的声音，仿佛来自你选定的方向。*整日发出随机且偶尔不合时宜的声响。* |
| **9** | **惑语术** | 一个生物必须大声且清晰地重复你所想的一切。除此之外它无法发声。*当文本被朗读时，他人的话语变得难以理解。* |
| **10** | **诱饵魔花** | 一株植物破土而出，散发着腐肉的气味。*引来苍蝇。* |
| **11** | **化兽术** | 你与你的随身物品化为一头寻常野兽。*覆着厚实毛皮，边缘缀满细齿。* |
| **12** | **迷乱术** | 你选定的一名生物在法术持续时间内无法形成新的短期记忆。*每次翻开，其内容都会变动。* |
| **13** | **移魂换躯** | 你与你触碰的生物交换身体。若其中一具躯体死亡，另一具也会随之死去。*封面上显示着上一个读过它的生物的形象。* |
| **14** | **魅惑术** | 你能看见的一名生物将你视为朋友。*触感温热，散发着玫瑰的芬芳。* |
| **15** | **命令术** | 目标服从一个三词以内的命令，且该命令不得对其造成伤害。*随岁月流逝愈发稀薄，直至最终永远消失。* |
| **16** | **通晓语言** | 你在短时间内通晓所有语言。*渗出字母，沾染所触之物。* |
| **17** | **泡沫锥** | 浓密泡沫自你手中喷涌，覆盖目标。*海绵般湿润，残留皂垢。* |
| **18** | **操控植物** | 附近的草木听从你的号令，并能以缓慢速度移动。*叶片沿脊背生长，隐约散发腐朽气息。* |
| **19** | **操控天气** | 你可随意改变天气类型，但无法进一步控制它。*对火焰与水流伤害具有极高抗性。* |
| **20** | **疗伤术** | 触碰一个生物，每日为其恢复1d4点力量。*气味如醋与百里香。用后泛红。* |
| **21** | **震聋术** | 附近所有生物陷入耳聋。*附近的乐器偶尔自行发声，仿佛在抗议。* |
| **22** | **侦测魔法** | 你能看见或听见附近的魔法灵光。*若附近有魔法被使用，书页会变得温热。* |
| **23** | **解体术** | 你的任何身体部位都可随意拆卸与接回，不会造成疼痛或伤害。你仍能控制它们。*能再生任何被撕毁或污损的书页。* |
| **24** | **易容术** | 你可随意改变一个角色的外貌，只要其仍保持人形。若试图模仿其他角色，会显得诡异不自然。*其表面是一面完美的镜子。* |
| **25** | **错位术** | 物体看似偏离实际位置至多 15 尺。*有时内里塞着些许线头、布片与树叶。* |
| **26** | **地震术** | 大地开始剧烈震颤。建筑或受损，或坍塌。*沙粒从角落簌簌落下，仿佛永无止歇。* |
| **27** | **柔身术** | 你的身体可伸展至多 10 尺。*散发太妃糖的气味，且极为柔韧。* |
| **28** | **元素之墙** | 一道冰墙或火墙自地面升起，长 50 尺、高 10 尺。*用后，皮肤与较温热的物质会粘附其上。* |
| **29** | **隔空取物** | 一件可见物品传送至你手中。*盟友珍视的财物，偶尔会出现在它的书页之间。* |
| **30** | **鱼鳃呼吸** | 目标可在水下呼吸，直至再次浮出水面。*散发着浓烈的海腥味。会吸引野兽。* |
| **31** | **闪光术** | 一团明亮的能量球拖着光尾射向天空，向敌友暴露你的位置。*在完全黑暗中微微发光。* |
| **32** | **云雾术** | 浓雾从你周身弥漫开来。*浸入水中时，此书终将把全部液体化为蒸汽。* |
| **33** | **狂乱术** | 附近一个生物爆发出狂暴的暴力。*粗糙如砂纸的封面，能毁掉任何触及的书。* |
| **34** | **异界之门** | 一道通往随机位面的传送门开启。*中央被凿出一个大洞，尽头是虚空。落入其中的物品再也不会出现。* |
| **35** | **重力反转** | 你可以改变重力的方向，但仅限自身。*会自动附着在附近最大的物体上。* |
| **36** | **贪婪术** | 一个生物会产生难以抑制的冲动，想要占有你指定的某件可见物品。*封面会随持有者而变，隐约透露出其内心最深处的渴望。* |
| **37** | **加速术** | 你的移动速度变为三倍。*翻开时书页会疯狂翻动。可能造成纸割伤。* |
| **38** | **仇恨术** | 一个生物会对另一个生物或群体产生深切的憎恨，并渴望将其毁灭。*长期接触此书会引发对他人的猜疑、偏执与不信任。* |
| **39** | **聆听低语** | 你能清晰地听见微弱的声音。*此后短时间内，读者的声音会被放大。* |
| **40** | **悬浮术** | 一个物体悬浮在离地 2 英尺处，无摩擦。最多可承载一个类人生物。*掉落时漂浮。* |
| **41** | **催眠术** | 一个生物进入恍惚状态，会如实回答你提出的一个是否问题。*封面上有引人注目的漩涡图案。* |
| **42** | **寒冰之触** | 一层厚冰在接触的表面上蔓延，半径可达 10 英尺。*需要手套。不可燃。* |
| **43** | **辨识旧主** | 你触摸的物体上方出现字母，拼出物体主人的名字（如果有的话）。*书的内部列出了前主人的名字。* |
| **44** | **光亮术** | 一个漂浮的光点随你指挥移动。*在光线下，书页变成充满活力的彩虹棱镜。* |
| **45** | **无形系索** | 彼此相距 10 尺内的两个物体无法被分开超过 10 尺。*其书页既无胶粘，也无线缝，却始终聚拢不散。* |
| **46** | **敲击开锁** | 附近一把 常规或魔法锁会大声解锁。*上锁。新主人在下一餐后“产出”钥匙。* |
| **47** | **跳跃术** | 你向上跳跃至多 10 尺高，仅一次。*被抛出时，它只是不停向前。* |
| **48** | **液化空气** | 你周围的空气变得可以游动。*自行漂浮，触物即弹。* |
| **49** | **抑魔结界** | 附近所有魔法效果的有效性减半。*法术书 100 尺内的奇物无法充能。* |
| **50** | **幻境华宅** | 一座坚固且配备家具的小屋会显现数小时。你可以随意允许或禁止他人进入。*若将书和小屋一同留下，两者将永远消失。* |
| **51** | **弹珠狂潮** | 你的口袋里装满了弹珠，并且每 30 秒会自动补充。*当被推挤时，会发出俏皮的咔嗒声。* |
| **52** | **群像伪装** | 一个角色的外貌和声音变得与你所触碰的角色完全相同。*长时间使用会导致原主产生无意识但明显的抽搐。* |
| **53** | **微缩术** | 你触碰的生物会缩小到老鼠大小。*文本大得荒谬可笑。* |
| **54** | **镜像术** | 一个你自己的幻影复制体出现并受你控制。*随着时间推移，持有者开始质疑谁是本体，谁是复制体。* |
| **55** | **镜界穿行** | 一面镜子会变成通往你今天曾照过的另一面镜子的门户。*除非主人礼貌地敲击镜盖，否则不会开启。* |
| **56** | **千手化形** | 你暂时多出一条手臂。*使用后，施法者会被幻肢综合征折磨一整天。* |
| **57** | **暗夜球幕** | 一个直径 50 英尺、展现夜空的黑暗球体出现在你面前。*其表面会显现一个醒目的星座。* |
| **58** | **化生为物** | 你变成任何介于三角钢琴和苹果之间的无生命物体。*使用后，主人会连续数日经历强烈的空想性错视。* |
| **59** | **软泥形态** | 你变成一团活体果冻。*缓慢滴落的酸液最终会腐蚀掉它接触的一切。* |
| **60** | **安抚术** | 你身边的一只生物厌恶暴力。*散发着茉莉与熏香的气味。吸引孩童。* |
| **61** | **穿行通道** | 在木、石或砖中开辟一条临时通路。*落在书上的物体，终会从另一侧坠落。* |
| **62** | **恐惧植根** | 附近的一只生物对你选定的某件物品陷入恐惧。*随着时间推移，诡异而抽象的画作开始填满它的书页。* |
| **63** | **陷坑术** | 地面上裂开一个宽 10 尺、深 10 尺的坑。*标准岩钉可安全收纳于书脊之中。* |
| **64** | **原初狂潮** | 一只生物迅速进化为其物种的未来形态。*持有者被自身先祖的奇异幻象所纠缠。* |
| **65** | **推拉斥引** | 任意大小的物体都会以一人之力被直接拉向你或推离你。*任何对抗这本书的力量都会被滑稽地放大。* |
| **66** | **唤起死尸** | 一具骷髅从地下升起为你效劳。它们极其愚蠢，只能执行简单的命令。*每次使用后，主人都会对骨骼愈发着迷。* |
| **67** | **招魂问答** | 附近一具尸体的灵魂显现，并回答 1 个问题。*答案（而非问题）将永远铭刻在它的书页上。* |
| **68** | **读心术** | 你能听到附近生物的表层思绪。*长期持有会让读者将他人的思绪误认为自己的。* |
| **69** | **斥退术** | 两个物体在 10 尺内会强烈地相互磁力排斥。*由两条强力束带合拢，会在不合时宜的时候弹开。* |
| **70** | **探知术** | 你能通过今日早些时候触碰过的生物的眼睛视物。*使用后，其主人的眼睛会变为乳白色，持续一小时。* |
| **71** | **塑形元素** | 无生命的材料在你手中如同黏土。*接触木头或布料会缓慢消解。埋入泥土或浸入水中可恢复。* |
| **72** | **感官移位** | 选择一种物品（钥匙、金币、箭矢、水壶等）。你能感知到最近的此类物品。*书的上一任主人始终知晓书当前的位置。* |
| **73** | **护盾术** | 你触碰的生物在一分钟内免受凡俗攻击。*以生锈的环甲装订，相当沉重。若持握，提供+1 护甲。* |
| **74** | **隐蔽帷幕** | 你触碰的生物在移动前处于隐形状态。*除书当前主人外，无人能看见。* |
| **75** | **移形换位** | 你可见的两个生物瞬间交换位置。*若被窃取但尚未阅读，它会在其主人最后留下它的地方重新出现。* |
| **76** | **巧手修复** | 你对一个非生物物体进行小修小补。*由一百本书的犊皮纸装订而成，没有两页是相同的。* |
| **77** | **睡眠术** | 你可见的生物陷入浅睡。*软如枕席，却只得断续之眠。* |
| **78** | **油腻术** | 30 尺半径内的所有表面变得极其湿滑。*处理时必须戴手套，否则书会以极其滑稽的方式掉落。* |
| **79** | **化烟术** | 你的身体化为可操控的活体烟雾。*闻起来像营火。书页无法被烧毁，但对湿气极为敏感。* |
| **80** | **敏锐嗅觉** | 你能嗅到最微弱的气味痕迹。*散发出只有其主人才能察觉的强烈气味。* |
| **81** | **熄光术** | 你视野内所有普通光源瞬间熄灭。*若长时间置于一处，附近光源会逐渐变暗，最终彻底熄灭。* |
| **82** | **归类术** | 无生命物品会按你设定的类别自行分类。*掉落或投掷时会自行摆正。* |
| **83** | **奥术飞锯** | 一道旋转的刀刃从你胸口飞出，清除沿途所有植物材料。除此之外无害。*以污渍斑斑的皮革包裹，每月至少需上油一次。* |
| **84** | **蛛行术** | 你能像蜘蛛一样攀爬表面。*每次使用前须拨开新结的蛛网。它们很难清除。* |
| **85** | **虫群召唤** | 你化作一群乌鸦、老鼠或食人鱼。只有*群攻*攻击能伤害你。*极易碎成十几块独立部分，随时间推移缓慢聚拢。* |
| **86** | **靶心诱引** | 你触碰的物体成为附近任何法术的目标。*吸引各种魔法生物、法术泄漏和探知。* |
| **87** | **念动术** | 你可以用意志移动 60 磅以下的物品。*持有者仅凭意念即可召唤此书（意志豁免，否则之后陷入匮乏）。* |
| **88** | **心灵感应** | 两个生物能听见彼此的思想，无论相隔多远。*持有者能听见（但无法回应）最后拥有此书者的思想，反之亦然。* |
| **89** | **传送术** | 你能看见的物体或人从一处传送到 50 英尺半径内的另一处。*可被摧毁以开启通往另一维度的传送门。* |
| **90** | **荆棘丛生** | 一片树丛与密灌突然冒出，宽至多 50 尺。*藤蔓缠绕，每次使用后都须再次摧毁。* |
| **91** | **时间操控** | 50 尺气泡内的时间减缓或加速 10%，持续 30 秒。*其外观在陈旧得不可思议与崭新写就之间交替。* |
| **92** | **真知术** | 你看穿附近所有幻象。*无法被魔法隐藏，且格外扎眼。* |
| **93** | **涌泉术** | 一道海水泉眼涌现。*硬化皮革装订，覆满盐渍与活藤壶。* |
| **94** | **幻象术** | 你完全控制一个生物所见之物。*封面上嵌着一只令人不安的无睑之眼。* |
| **95** | **视觉幻影** | 一道寂静无声、无法移动、与你等身大小的幻象凭空出现，形态由你决定。*书页丰盈多彩，宛如一本孩童的睡前故事。* |
| **96** | **防护法阵** | 地面上浮现一道直径五十尺的银色圆环。选择一种无法跨越它的生物。*封面上绘满怪诞的异界生物，生着千百只眼睛。* |
| **97** | **蛛网术** | 你的手腕射出浓稠的蛛丝。*文字陌生难辨，却又莫名可解，因为那是梦的语言。* |
| **98** | **巧造奇物** | 一件所绘工具的原始版本出现在你面前，片刻后便消失无踪。*散发着铁与锈、汗与力的气息。书页深处隐约传来粗重劳作的声响。* |
| **99** | **法师印记** | 你的手指能射出一道幽火色的颜料。此颜料唯你可见，无论距离多远，甚至能穿透实体。*封面前页内侧有个小口袋，装着一沓薄纸，列着此前所有主人的姓名与死期。* |
| **100** | **透视之眼** | 你能看穿墙壁、泥土、衣物等。*长期暴露会导致脱发、视力模糊和疲乏。* |
