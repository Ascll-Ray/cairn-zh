# Cairn 第二版规则参考

《石冢》（Cairn 2e）中文规则参考与官方第一方模组 CAS-1《双湖纷扰》。

本项目基于 [Astro 5](https://astro.build) 与 [Starlight](https://starlight.astro.build) 构建，采用冷峻纯暗色设计风格，提供完整的移动端适配与 Pagefind 中文即时检索。
